# Security Policy

## Supported Versions

Only the latest release of Aster is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Aster seriously. If you believe you have found a security vulnerability in Aster, please do **NOT** open a public issue on GitHub.

Instead, please report it privately:
- Through GitHub Private Vulnerability Reporting on this repository; or
- By reaching out to the maintainers directly.

Please include the following information in your report:
- Type of issue (e.g., local privilege escalation, authentication bypass, CSRF)
- Steps to reproduce the issue
- Affected components (e.g., `aster-helper`, `aster-daemon`, Swift UI)
- Any potential remediations or mitigation suggestions

We will acknowledge receipt of your report within 48 hours and work with you to analyze and address the issue before public disclosure.
